## 简体中文

在 Bambu Studio 的菜单栏选择 **Bambu Studio → 服务 → 打印配色核对**，即可打开 3D 配色预览。助手已经打开时，这个命令会调回原窗口，保留视角和选中的耗材。中英文 README 收录了熊猫吃西瓜的实机截图，可以放大查看舌头、瓜皮和对应的 AMS 槽位。

下载 **BambuPrintColorCheck-0.4.0-macOS-arm64.zip**。退出旧版助手，解压，将 App 拖入“应用程序”并打开一次。菜单入口会注册到官方版 Bambu Studio。适用于 Apple 芯片 Mac 和 macOS 14 或更高版本。测试包使用本地签名，尚未获 Apple 公证。

## English

Choose **Bambu Studio → Services → Print Color Check** from the Mac menu bar to open the 3D preview. If the helper is already running, the command brings back the same window with its camera angle and filament selection. Both READMEs include the Chinese and English panda screenshots so you can inspect the tongue, watermelon rind, and corresponding AMS slots at full size.

Download **BambuPrintColorCheck-0.4.0-macOS-arm64.zip**. Quit the old helper, extract the ZIP, move the app to Applications and open it once to register the command in the official Bambu Studio app. Requires an Apple silicon Mac running macOS 14 or later. This beta is ad-hoc signed and has not been notarized by Apple.
