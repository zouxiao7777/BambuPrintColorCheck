## 简体中文

首个公开测试版。用 AMS 槽位登记的颜色重绘切片外表面，在发送任务前检查每种耗材会打印在哪个部位。支持旋转、局部放大、按耗材突出显示和 4K 导图。

**下载 `BambuPrintColorCheck-0.3.0-macOS-arm64.zip`**，解压后将 `BambuPrintColorCheck.app` 拖入“应用程序”。适用于 Apple 芯片 Mac，最低系统要求为 macOS 14。附件含中英文安装说明和 `SHA256SUMS.txt` 校验清单。

新增双语“关于”页，可从工具栏或应用菜单打开，查看使用步骤、版本、下载、源码和作者联系方式。已在 macOS 26.5、Bambu Studio 2.9.1.70 和 H3C 单口径模式的浅色耗材卡环境验证。应用使用本地签名，尚未获 Apple Developer ID 签名或公证。

## English

First public beta. Inspect the exterior of a sliced model in the colors registered for its assigned AMS slots before sending a print. Rotate the model, zoom into a detail, highlight a filament’s region, or export a 4K comparison.

**Download `BambuPrintColorCheck-0.3.0-macOS-arm64.zip`**, extract it and drag `BambuPrintColorCheck.app` to Applications. Requires an Apple silicon Mac running macOS 14 or later. Installation guides in both languages and SHA-256 checksums are attached.

The bilingual About page is available from the toolbar and the application menu. It includes instructions, version information, downloads, source code and author contact. Tested on macOS 26.5 with Bambu Studio 2.9.1.70 and H3C single-nozzle-diameter mode using light-mode filament cards. The app is ad-hoc signed, without Developer ID signing or Apple notarization.
